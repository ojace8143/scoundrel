## the actual game rules
* 44 card deck. no jokers, red face cards, and red aces.
* 26 "monsters" (the black cards), and 18 red cards (health pots and weapons)
* dungeon contains 4 cards each, lied out. only 3 cards need to be "resolved"

[official game rules](https://stfj.net/art/2011/Scoundrel.pdf)
